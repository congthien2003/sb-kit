# Proposal visualization

Use this reference when the page must help a reader decide on a recommended change. The reader finishes knowing what is proposed, why it beats the alternatives, and what they must decide.

## Sections

These sections guide the reading sequence. Follow the section rules in `SKILL.md` to adapt them to the content.

| # | Vietnamese | English | Presence | Contains |
|---|---|---|---|---|
| 1 | Ngữ cảnh | Context | Core | Why this topic is on the table now |
| 2 | Hiện trạng | Current state | Optional | What exists today and the problem it causes |
| 3 | So sánh phương án | Options | Optional | The options the source considers, in `.options` or a table |
| 4 | Đề xuất | Recommendation | Core | The chosen option and the reasons, in a `callout-good` or `.option-chosen` |
| 5 | Rủi ro và chi phí | Risks and cost | Optional | What could go wrong and what it takes |
| 6 | Việc cần quyết định | Decisions needed | Optional | The decisions and next steps, as a list or `.checklist` |

The takeaway in the page header states the recommendation in one sentence.

## Source fidelity

Never invent options, costs, risks, or decisions. If the source names one option only, omit section 3 rather than creating an alternative to compare against. If the source recommends nothing, omit section 4 and say so in the takeaway.
