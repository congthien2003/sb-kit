Cách hoạt động

Bốn bước, không có bất ngờ.

Cancel ở bất kỳ bước nào cũng dừng trước khi tạo hay copy skill folder.

  1. 01 · đọc

    Đọc catalog

    CLI đọc danh sách thư mục skill trong .agents/skills của package.

  2. 02 · chọn

    Preset rồi checkbox

    Chọn Manual hoặc preset Minimal / Full-stack / UI / Reporting, rồi chỉnh checkbox theo category sk-work, assets hoặc report.

  3. 03 · xung đột

    Giữ hay thay

    Install missing only giữ nguyên skill đã có; Replace selected chỉ thay đúng skill đã chọn. Xem giải thích bằng npx sb-kit --help.

  4. 04 · mirror

    Claude Code tuỳ chọn

    Chọn Yes để mirror cùng selection và mode sang .claude/skills. No là mặc định.

Core kit

Mỗi skill một việc, làm có evidence.

SaboKit core / 13 skills

sk-excute

core

Inline-first cho task low/medium: đọc code và docs → bạn duyệt spec → đọc bổ sung, lập plan/todo và tự review → bạn duyệt plan → triển khai, review/sửa findings và bàn giao. Advisor sẵn có trong session và worker đều tùy chọn; task nhỏ vẫn giữ đủ hai approval gates.

sk-excute-explorer

core

Contract cho scout read-only: tìm evidence về code và tài liệu local còn thiếu, trả paths, contracts và risks. Tái sử dụng kết quả, không bắt buộc scout lại cho plan.

sk-excute-researcher

core

Researcher trả citations cho câu hỏi public external cần thiết, tuân thủ consent/privacy và ưu tiên primary source đúng version.

sk-excute-implementer

core

Contract cho worker tùy chọn: triển khai nhóm task đã duyệt với exclusive file ownership, rồi handback files và evidence để agent chính review, integrate và sửa.

sk-visualizer

core

Biến prompt, spec, plan, hoặc nội dung hội thoại thành một file HTML visualization trực quan, dễ đọc. Hỗ trợ nhiều style preset, tự động responsive, có timeline và diagram.

sk-create-slide

core

Tạo HTML presentation từ ý tưởng hoặc chuyển đổi PPT/PPTX.

sk-release

core

Chuẩn bị release với draft changelog, đề xuất SemVer, summary và checklist; không tự commit, push hoặc tag.

sk-doc

core

Sinh README, API docs, changelog hoặc usage guide từ codebase thành một file Markdown.

sk-explain

core

Giải thích source code, flow, state transition và các nhánh xử lý dựa trên file references.

sk-verify-code-ui-only

core

Audit tĩnh việc tái sử dụng component, typography và spacing theo chuẩn repo, với bằng chứng file:line. Chỉ kiểm tra UI; không sửa code, hooks, services hay logic nghiệp vụ, và không chạy autofix. Có thể chia page/section cho native sub-agents nếu host hỗ trợ và cho phép.

sk-review-diff

core

Review diff được chọn với severity, location và evidence. Phân biệt regression và vấn đề có sẵn; không tự patch/verify.

sk-idea-to-docs

core

Biến ý tưởng thành overview, spec và implementation plan: hỏi từng câu, lấy phản hồi trước khi lập plan; dừng ở docs, không triển khai.

sk-start-next-hono

core

Hoàn thiện workspace Next.js + Hono đã bootstrap: giữ Node.js mặc định hoặc chuyển backend sang Cloudflare Workers sau khi duyệt plan, không buộc chuyển Next.js. Hướng dẫn PostgreSQL/Drizzle, auth/proxy với Origin guard, cleanup database và R2 tùy chọn.

deep-research

sk-landing-page

support

Tạo hoặc cập nhật landing page sản phẩm tại landing/index.html, với concept, typography và bố cục phù hợp bằng Tailwind CSS CDN.

Works together

Chốt hướng bằng sk-excute, trình bày bằng sk-visualizer.

Agent chính giữ ownership từ spec, plan đến implementation và final review. Bạn duyệt ở hai cổng; khi cần nhìn spec hay plan trực quan, sk-visualizer biến chúng thành một trang HTML.

  1. 01 Investigate Agent chính đọc source, scout chỉ đi tìm evidence còn thiếu.
  2. 02 · approval gate Spec Viết spec. Bạn duyệt trước khi đi tiếp.
  3. 03 · approval gate Plan Plan và todo đã self-review. Bạn duyệt lần hai.
  4. 04 Implement Triển khai inline; worker chỉ nhận task đã duyệt.
  5. 05 · tuỳ chọn Visualize sk-visualizer trình bày spec hoặc plan thành trang HTML.

Chỉ đọc

sb-kit doctor

Inspect .agents/skills và .claude/skills: skill nào unchanged, local-modified hay upstream-changed, companion nào còn thiếu. Thêm --json cho CI; exit 0 là clean, 1 cần chú ý, 2 là lỗi metadata hoặc mutation đang pending.

Có backup

sb-kit update

Preview file added/removed/changed trước khi thay, yêu cầu consent thêm cho bản sửa local, và lưu backup tại .sb-kit/backups/. Final confirmation mặc định No; cancel trước apply không tạo backup hay metadata.

MCP server

Một file memory cho mọi session.

memorize-mcp lưu shared Markdown memory vào .memorize/MEMORY.md của workspace. Không cloud sync, không database; file giới hạn 64 KiB để agent đọc và tìm trực tiếp.

memorize-mcp

v2.0.1

Đăng ký session, ghi theo section, tìm lại context của workspace.

MCP server 3 tools Live
01
start_session Đăng ký session mới mà không xoá memory đã có. Nhận goal tuỳ chọn.
02
save_memorize Ghi Markdown theo section, mode append để cập nhật tiến độ hoặc replace để thay một section.
03
search_memorize Không truyền query để nạp toàn bộ context; truyền query, section hoặc sessionId để lọc.
