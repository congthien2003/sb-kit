Bên trong sk-excute

Agent có quy trình.
Bạn giữ quyền quyết định.

Tính năng mới hay một bug cần sửa đều bắt đầu từ việc hiểu codebase. Workflow yêu cầu điều tra, review và duyệt phương án trước khi triển khai.

  1. 01

    Hiểu codebase

    Thu thập evidence, chọn mức light hoặc full theo phạm vi và rủi ro.

  2. 02

    Review spec và plan

    Light gộp spec và plan để review, duyệt một lần. Full review và duyệt từng phần riêng.

  3. 03

    Duyệt kèm cách làm

    Thống nhất Inline hoặc Sub-agent cùng lúc duyệt plan. Giữ lựa chọn đã rõ cho task.

  4. 04

    Triển khai và kiểm tra

    Kiểm tra evidence còn hợp lệ, thực hiện plan đã duyệt và báo kết quả xác minh.

Không tự commit. Báo rõ phần đã kiểm tra và phần chưa xác minh.

Đưa workflow vào project

Bắt đầu với project hiện tại

Chọn skills.
Cài vào project.
Bắt đầu làm việc.

Bạn cần Node.js từ 20.12.0, npm/npx và quyền tạo thư mục trong project đích.

Đang bắt đầu project mới? ↓
  1. 1

    Mở terminal tại thư mục project

    Chạy lệnh sau để mở bộ chọn skills:

    npx sb-kit install

  2. 2

    Chọn skills và cách cài

    Dùng phím mũi tên và Space để chọn, Enter để tiếp tục. Giữ Install missing only để bảo toàn skills có sẵn, hoặc chọn Replace selected để thay những skills đã tick.

    Ở câu hỏi cài thêm cho Claude Code, chọn Yes nếu cần. No là mặc định.

  3. 3

    Gọi skill trong coding agent

    Mở project bằng công cụ hỗ trợ skills và nêu yêu cầu của bạn. Ví dụ sau khi cài sk-excute:

    “$sk-excute Thêm tính năng tìm kiếm. Đọc code hiện tại và đề xuất phương án trước khi sửa.”

Cho một khởi đầu mới

Next.js + Hono.
Một workspace để bắt đầu.

Khởi tạo pnpm workspace với Next.js App Router, Hono chạy trên Node.js và bộ core skills của sb-kit.

Cần cài pnpm. Thư mục đích phải mới hoặc rỗng.

npx sb-kit create next-hono my-app

Đây là workspace nền. Dùng prompt bàn giao của CLI với $sk-start-next-hono để cấu hình database, auth và proxy sau khi duyệt plan. R2 chỉ thêm khi bạn yêu cầu.

Trước khi bắt đầu

Bạn có thể
đang thắc mắc.

sb-kit là gì?

sb-kit là CLI cài bộ agent skills được đóng gói sẵn vào project. Mỗi skill cung cấp hướng dẫn cho một loại công việc, từ triển khai tính năng đến thiết kế, viết tài liệu và chuẩn bị release.

Skills có sẵn trong project có bị ghi đè không?

Mặc định, Install missing only bỏ qua những thư mục skill đã tồn tại. Nếu chọn Replace selected, CLI chỉ thay những skills bạn đã tick. Những skills không chọn không bị ảnh hưởng.

Tôi có cần dùng Claude Code không?

Không bắt buộc. Skills luôn được cài vào .agents/skills để dùng với công cụ hỗ trợ cấu trúc này. Cài thêm vào .claude/skills là lựa chọn riêng, mặc định là No.

sk-excute có luôn chạy nhiều agent không?

Không. Sub-agent phụ thuộc khả năng dispatch của công cụ bạn dùng. Khi không hỗ trợ, điều tra và review có thể thực hiện inline và phải báo rõ. Nếu bạn đã chọn triển khai Sub-agent nhưng công cụ không hỗ trợ, workflow sẽ hỏi chuyển sang Inline hoặc dừng. Nghiên cứu bên ngoài chỉ được giao khi bạn yêu cầu rõ.

Workspace mới đã có database và đăng nhập chưa?

Chưa. Lệnh create dựng Next.js + Hono cùng tooling và core skills. Sau đó bạn dùng $sk-start-next-hono để agent đề xuất và triển khai PostgreSQL, Drizzle, auth, proxy và các convention theo plan được duyệt.

Skills có tự commit hoặc chạy kiểm tra không?

Workflow sk-excute không tự commit khi chưa được yêu cầu. Việc chạy build, test, lint hay kiểm tra khác phải tuân thủ instructions của repository và quyền bạn cho phép; kết quả bàn giao cần phân biệt rõ những gì đã kiểm tra với phần chưa xác minh.
