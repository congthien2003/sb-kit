Reference map

Chọn recipe theo câu hỏi người đọc cần trả lời

Mỗi reference là một hướng dẫn riêng, không phải template dùng chung cho mọi nội dung.

Reference Dùng khi Trọng tâm
system-change-report.md Cần triage thay đổi hệ thống Severity, affected areas, impact và action
spec-visualization.md Cần làm spec dễ đọc Reading-first document và key decisions
implementation-plan.md Cần truyền đạt kế hoạch triển khai Delivery path, scope và verification

Output contract

Một file, một mục tiêu, dependency minh bạch

Mỗi lần chạy tạo đúng một file .html. Trang chỉ thêm CDN khi có block tương ứng và không mô tả file là self-contained nếu cần tài nguyên bên ngoài.

Các block được hỗ trợ

Hero, Steps, Matrix/Table, Callout, Details, Diagram, Code, Compare và Checklist. Skill chọn số block ít nhất để truyền tải takeaway.
